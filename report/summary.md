# VAST Challenge 2018 MC1 - Environmental Investigation Platform

## Executive Summary

This project is a submission to the VAST Challenge 2018 Mini-Challenge 1. It presents an interactive visual analytics platform designed to investigate a critical environmental mystery: a nature preserve (Boonsong Lekagul) is home to endangered Rose-Crested Blue Pipits, and a furniture company (Kasios) claims to have recorded 15 healthy Pipit calls throughout the preserve. However, officials suspect the recordings may be fabricated or manipulated, potentially covering up evidence of ecological damage.

### Core Investigation Questions

1. **Are the 15 Kasios recordings authentic Pipit calls, or are they fabricated/manipulated?**
2. **How has the Pipit population moved and changed density over time across the preserve?**
3. **Can we pinpoint the exact location of alleged toxic dumping by finding population anomalies?**

## Data & Format

### Input Data Files

**AllBirdsv4.csv** — The verified historical bird database

- Contains 2,000+ high-confidence bird recordings with complete metadata
- Columns: File ID, species name, vocalization type (call/song), quality rating, timestamp, X/Y coordinates within the preserve
- Format: Tab-separated values with proper header row
- Purpose: Serves as the ground-truth training data for machine learning classification and baseline for temporal/spatial analysis

**Test Birds Location.csv** — The suspicious recordings under investigation

- Contains 15 recordings submitted by Kasios as purported Pipit calls
- Columns: File ID, GPS coordinates, submission timestamp, claimed species
- Format: CSV with headers
- Purpose: The samples to be analyzed and verified against the historical database

### Generated Data Files (JSON)

**map_data.json** — Preprocessed spatial and temporal bird data

- Generated by `preprocess_map_data.py` from AllBirdsv4.csv
- Contains cleaned and normalized bird call records with temporal breakdown (Year, Month, YearMonth)
- Format: JSON array of objects with fields: fileID, species, vocalizationType, timestamp, x, y, year, month
- Purpose: Powers the interactive MapDashboard for geospatial and temporal filtering

**comparisons_ml.json** — Machine learning classification results

- Generated by `classify_audio.py` comparing each Kasios file against the verified bird database
- Contains classification scores, predicted species, confidence levels, and nearest-neighbor matches
- Format: JSON with per-file classification data, top-k predictions, and distance metrics
- Purpose: Fuels the LieDetector component to determine if Kasios files are authentic or fabricated

### Audio File Directories

**data/ALL BIRDS/** — Complete verified audio archive

- Contains 2,000+ MP3/WAV audio files corresponding to AllBirdsv4.csv
- Named consistently with database file IDs for easy cross-referencing
- Used for feature extraction and spectrogram comparison

**data/Test Birds from Kasios/** — Suspicious audio files under investigation

- Contains 15 MP3/WAV files submitted by Kasios
- Each file corresponds to a record in Test Birds Location.csv
- Analyzed through both machine learning and visual spectrogram comparison

## Code Architecture & Data Processing Pipeline

### Technology Stack

- **Frontend Framework**: Next.js 16 with React 19
- **UI Styling**: Tailwind CSS + PostCSS
- **Visualization Libraries**: D3.js 7 (mapping), WaveSurfer.js (audio playback)
- **Audio Processing**: Web Audio API (real-time FFT for spectrograms)
- **Backend**: Next.js API routes (`app/api/audio/route.ts`) to serve audio files
- **Data Processing**: Python 3 (scikit-learn, NumPy, Pandas)
- **Deployment Ready**: Configured for Vercel hosting

### Python Data Pipeline

**preprocess_map_data.py** — Data Cleaning & Temporal Extraction

- Parses AllBirdsv4.csv raw bird recording database
- Extracts and normalizes temporal information: Year, Month, YearMonth combinations
- Cleans vocalization type classifications (standardizes call/song categories)
- Removes incomplete or duplicate records
- Exports preprocessed data as map_data.json for frontend consumption
- Output size: ~500KB JSON file with 2,000+ records

**classify_audio.py** — Machine Learning Audio Classification Pipeline

- **Feature Extraction Phase**:
  - Processes each audio file and extracts a 173-dimensional feature vector
  - Spectral features: MFCC (Mel-frequency cepstral coefficients), chroma energy, spectral contrast
  - Temporal features: call rate, chirp duration, frequency transitions
  - Normalization: StandardScaler applied to ensure feature comparability
- **Model Training Phase**:
  - Trains on verified birds from AllBirdsv4.csv audio directory
  - Uses a VotingClassifier ensemble combining:
    - Random Forest (100 trees, captures non-linear patterns)
    - Extra Trees (captures feature importance diversity)
  - Cross-validation ensures model generalization
- **Classification & Comparison Phase**:
  - Extracts features from each of the 15 Kasios files
  - Classifies against the trained ensemble to predict species
  - Computes distance metrics (cosine similarity, Euclidean) to nearest verified matches
  - Outputs top-k predictions with confidence scores
  - Generates comparisons_ml.json with detailed results for each Kasios file

## Visualization Components & Features

### 1. MapDashboard — Geospatial & Temporal Analysis

**Purpose**: Investigate how the Pipit population has moved and changed density across the preserve over time.

**Data Source**: Loads preprocessed bird call data from `map_data.json`

**Visual Representation**:

- **Interactive 2D scatter plot** displaying the preserve as a 200×200 coordinate space
- Each point represents a single bird vocalization event
- **Shape encoding**:
  - Circles = call vocalizations
  - Triangles = song vocalizations
  - Squares = other vocalization types
- **Color encoding**: Different species displayed in distinct D3 categorical colors
- **Heatmap mode**: Alternative view showing call density as continuous color gradient

**Interactive Controls**:

- **Year/Month Slider Range**: Dynamically filter data by time period (e.g., "show all calls from May 2015 to July 2016")
- **Species Selector**: Toggle individual species on/off to isolate specific birds
- **Vocalization Type Filter**: Show calls only, songs only, or both
- **View Mode Toggle**: Switch between scatter plot (individual points) and heatmap (continuous density)
- **Animation/Playback Mode**: Time-lapse visualization showing how population moves month-by-month
- **Dual Comparison View**: Side-by-side maps to visually compare two different time periods simultaneously
- **Tooltip Interactions**: Hover over points to see file ID, species, vocalization type, and exact timestamp

**Investigative Use Cases**:

- Identify temporal population changes (are Pipits disappearing from certain areas?)
- Spot geographic gaps or anomalies (dead zones where calls suddenly stop = possible dumping areas)
- Compare population distribution before/after suspected toxic events
- Detect seasonal migration patterns vs. abnormal movement

---

### 2. LieDetector — Audio Classification Dashboard

**Purpose**: Determine if each Kasios recording is authentic or fabricated by comparing it against the verified bird database.

**Data Source**: Loads machine learning classification results from `comparisons_ml.json`

**Visual Layout**:

- **File Selector Dropdown**: Choose any of the 15 suspicious Kasios recordings to analyze (displays file ID and submission date)
- **Classification Display Panel**: Shows the ML model's predicted species and confidence score
- **Best Match Information**: Displays the closest matching verified bird recording (file ID, species, similarity score)

**Two Comparison Modes**:

1. **"Claimed Pipit" Mode**: If Kasios claims this file is a Rose-Crested Blue Pipit, compare it against the best verified Pipit in the database
   - Shows how well the file matches the "claimed" species
   - High similarity = potentially authentic; low similarity = likely fabricated
2. **"Actual Match" Mode**: Compare the Kasios file against what the ML classifier thinks it most closely resembles
   - May reveal that a file is actually a different bird species entirely
   - Indicates if Kasios misidentified their own recordings (intentionally or accidentally)

**Display Information**:

- Classification species prediction
- Confidence percentage (how certain the model is)
- Distance metric to best match (lower = more similar)
- Top 3-5 candidate species with scores
- File ID and metadata of the best-matching verified recording

**Investigative Use Cases**:

- Quickly scan all 15 files for obvious mismatches (if model says "this is a sparrow, not a Pipit" → likely fabricated)
- Compare claimed species vs. actual ML prediction (large discrepancies suggest manipulation)
- Build forensic evidence: which files are suspicious vs. which might be authentic

---

### 3. AudioVisualizer — Spectrogram Comparison & Forensics

**Purpose**: Perform detailed audio forensics by comparing waveforms and spectrograms side-by-side to detect fabrication or manipulation.

**Data Source**: Loads audio files from the backend API (`/api/audio`) and processes them in real-time

**Visual Representation**:

**Waveform Display**:

- **Orange waveform**: Time-domain representation of Kasios (suspicious) recording
- **Indigo waveform**: Time-domain representation of a verified bird recording
- Shows amplitude over time for quick visual pattern matching
- Identical waveforms = likely authentic; completely different patterns = likely fabricated

**Spectrogram Display** (Mel-scale FFT):

- Real-time generation using Web Audio API
- FFT window size: 1024 samples
- Mel-scale frequency mapping for perceptual accuracy (humans hear logarithmic frequencies)
- **Color mapping**: White (silence/low energy) → Light colors (medium energy) → Indigo-950 (loud peaks)
- Two spectrograms displayed side-by-side: Kasios vs. verified bird
- Time axis: Linked across both views for synchronized comparison
- Frequency axis: Aligned for direct pitch comparison

**Interactive Controls**:

- **Play/Pause buttons**: Control audio playback of both recordings
- **Time scrubbing**: Click/drag to jump to any position in the audio
- **Volume controls**: Adjust playback volume for each recording independently
- **Speed control**: Slow down or speed up playback to hear subtle details
- **Zoom controls**: Magnify time or frequency axes to examine fine details

**Visual Forensic Analysis**:

- **Spectral peaks**: Identical frequencies at same timestamps = authentic match
- **Harmonic structure**: Natural birds have harmonic overtones (multiples of fundamental frequency); synthetic/manipulated audio often lacks this
- **Noise patterns**: Environmental background noise should match between authentic recordings from the same location
- **Frequency sweeps**: Rising/falling pitch patterns should match natural call characteristics
- **Temporal structure**: Call duration, silence gaps, and repetition patterns should be consistent

**Investigative Use Cases**:

- Forensic comparison: overlay a Kasios file against a verified Pipit call to spot fabrication
- Detect audio splicing: discontinuous waveforms or frequency gaps indicate cut-and-paste manipulation
- Identify synthetic generation: lack of realistic harmonic structure or unnatural frequency transitions
- Confirm authenticity: matching spectrograms = strong evidence the file is genuine

## Interactive Website Features & User Workflow

### Single-Page Application Layout

The website is implemented as a full-screen Next.js application with two major visualization components stacked vertically:

1. **MapDashboard** — Occupies the top half/full width
2. **LieDetector + AudioVisualizer** — Occupies the bottom half/full width (or side-by-side on larger screens)

### Recommended Investigation Workflow

**Step 1: Explore the Preserve**

- Load the MapDashboard
- Use year/month sliders to examine historical Pipit population distribution
- Look for geographic clusters, seasonal patterns, and anomalies
- Toggle species on/off to focus on Pipits
- Use animation mode to watch population changes unfold over time
- **Question to answer**: Where did Pipits historically live? Are there suspicious population gaps?

**Step 2: Identify Suspicious Locations**

- Use dual comparison mode to compare population before/after suspected toxic event dates
- Look for dramatic drops in call density in specific areas
- Note geographic coordinates of population anomalies
- **Question to answer**: Where are the "dead zones" where Pipits have disappeared?

**Step 3: Analyze Kasios Files**

- Scroll to the LieDetector component
- Open the file selector dropdown to load each of the 15 Kasios recordings
- Check the ML classification results: is it really a Pipit?
- Compare "Claimed Pipit" mode vs. "Actual Match" mode for discrepancies
- **Question to answer**: How many Kasios files are actually authentic Pipits?

**Step 4: Forensic Audio Analysis**

- Select a suspicious file in the LieDetector
- Switch to the AudioVisualizer component
- The system auto-loads the Kasios file and a top-matching verified bird from the database
- Compare the waveforms: do they look similar in structure?
- Examine the spectrograms: do the frequency patterns match?
- Look for signs of splicing, synthesis, or other manipulation
- **Question to answer**: Is this file authentic or fabricated?

**Step 5: Synthesize Conclusions**

- Compile results: how many Kasios files are genuine vs. fabricated?
- Cross-reference with geographic anomalies: do Kasios file locations correlate with population dead zones?
- Use visual evidence (spectrograms, waveforms, ML scores) to build your case
- **Answer the three investigation questions** with data-driven conclusions

### Responsive Design & Interactivity

- **Tailwind CSS styling** ensures mobile-responsive layout
- **Smooth interactions**: slider ranges, dropdown selections, tooltip hovers all provide immediate visual feedback
- **Color-coded feedback**: High confidence scores displayed in green, low confidence in red/orange
- **Loading states**: Components show loading spinners while data is being fetched
- **Tooltips & legends**: Hover information explains every visual encoding (color, shape, size)
- **Error handling**: Missing audio files or incomplete data display graceful error messages

## Summary

This project represents a comprehensive visual analytics solution to a complex environmental investigation. By combining geospatial analysis, temporal filtering, machine learning classification, and interactive audio forensics, the platform enables investigators to:

1. **Understand historical Pipit populations** through interactive mapping
2. **Detect suspicious population anomalies** that may indicate ecological damage
3. **Verify audio authenticity** using machine learning and spectrogram comparison
4. **Build forensic evidence** through visual and computational analysis
5. **Draw data-driven conclusions** about Kasios's claims and environmental impact

The platform is a fully functional, production-ready Next.js application that bridges data science (Python ML pipeline) with interactive visualization (React + D3.js), providing a powerful tool for environmental forensics and ecological investigation.
